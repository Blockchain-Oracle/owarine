## Committee-attested event (an Addition)

`scripts/drive/committee-event.ts` ran against the live stack:

1. `create --id DEMO-1 --minutes 10` created Series `EVT-DEMO-1` with print source `attested:committee:DEMO-1` and committee = the three oracle parties, quorum 2. It opened Window `11:02–11:12Z`.
2. `open` had all three members attest the 1.0 baseline. The resolver then recorded the open at 1.0 (3 oracles).
3. `attest --outcome yes` ran after 11:12. A try at 11:11:48 was refused ("can be attested from 11:12:00, not before"). The resolver recorded `resolved EVT-DEMO-1:0 Up 1.0 → 2.0 (3 oracles)`, which reads as YES. The `Resolution` is signed by the resolver and the venue.

Each member's statement (question, outcome, member, time) is hashed into its `payloadHash`. The board lists registry tickers only, so the event never renders as a lane.

## Found and fixed during the run

- The projector reads `VENUE_PARTY` from env, not from the parties file, so the run set it.
- The web needs `NEXT_PUBLIC_AGARI_INDEXER_URL=/api/index`.
- With no calendar, the web hid every lane state, including 24/7 pauses. Fixed in C6.5 (`useLaneStates`).
- The PreStocks health probe raced the feed at boot and drew a 429, which paused pre-IPO lanes for 5 minutes. Fixed in the C6.3 probe follow-up.

## Daml changes this lane would need (not made; 0.3.0 frozen)

1. **Monday Gap.** `Series_OpenWindow` fixes `expiry = tradingStart + cadence` and `lockAt = expiry − lockLeadSec`. A Gap runs from Friday close to Monday open (Tuesday after a holiday) and locks Sunday 20:00 ET, so its length varies and it cannot sit on a fixed grid. It needs an open choice that takes the Window's boundaries (`Series_OpenWindowAt with tradingStart, lockAt, expiry`, checked against the policy and `nextIndex`) or a Gap Series template. The planner (`plan-gap.ts`) is already ported.
2. **Committee events, first-class (optional).** Events currently ride `Terms_Resolve` with a 1.0 → 2.0/0.5 encoding. An `EventTerms` with a question, a YES/NO outcome and a `Terms_Attest` choice would make the ledger read as an event.
