---
title: "Glossary"
description: "A plain explanation of the words Agari uses."
---

| Term | Meaning |
| --- | --- |
| **Canton** | Canton Network, the ledger Agari runs on. A contract there is visible only to the parties on it. |
| **Party** | An identity on Canton. The venue, the resolver and each oracle are parties; so is each seat. |
| **Seat** | Your place at the venue: a signing key in your browser that cannot leave it, and a Canton party the venue leases to you. See [your seat](/start/wallet). |
| **Demo credits** | The venue's test money on a Canton test network. Worth nothing anywhere else. |
| **Window** | One tradeable period on one ticker: an opening print, a closing print, one cadence. |
| **Series** | A ticker + cadence pair (for example BTC-5m). Holds the oracle list, the quorum and the price policy its Windows use. |
| **Quote** | The venue's firm offer: one side of one Window at one price, valid for a few seconds. Accepting it opens your position. |
| **Position (leg)** | Your side of a call. Only your seat's party and the venue can see it. |
| **Print** | A price for one boundary (open or close) of a Window, posted and signed by an oracle party. See [price sources](/architecture/price-sources). |
| **Oracle party** | One of three parties that post prices, one per exchange. A Window needs a quorum of 2. |
| **Resolver** | The party that settles or voids each Window, exactly once, from the oracle prints. |
| **Policy version** | A Series' price-source rule for a date range. Registered in advance; never edited once written. |
| **Void** | A Window that settles no winner, because too few prints arrived or they disagreed too much. Your stake and your fee return. |
| **Proof page** | `/proof`: every settled Window with its prints, the oracle that signed each, and the evidence behind them. |
| **24/7 lane** | Windows that trade around the clock. Today these are the crypto lanes. |
| **Cover** | A Down call a holder takes as insurance on tokens they hold. **Planned** on Canton: a seat holds no outside tokens yet. |
| **Schedule a call** | A call rested on a Window before it opens; see [pre-open calls](/trading/pre-open-calls). |
| **Short** | A Down position with an exit at any time and a knock-out line; see [Short a fall](/trading/shorts). **Planned** on Canton. |
| **Halt** | A wide or issuer-level trading halt signal. Shown as "Trading halted." A merely stale price print is shown as "Signed price stale" instead — a different, more common state. |
