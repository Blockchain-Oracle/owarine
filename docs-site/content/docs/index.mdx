## More resources

Owarine is a prediction market on Canton Network. You can browse <AppLink href="/markets">Markets</AppLink> and <AppLink href="/proof">Proof</AppLink> without a seat. **Predict** uses demo credits, and each position is visible only to your seat and the venue. Everything described here runs end to end on a local Canton sandbox today; it is not yet on Canton DevNet or a hosted URL. Start with [your seat and demo credits](/start/wallet) for a call, or [the price sources](/architecture/price-sources) to see how a Window settles.
