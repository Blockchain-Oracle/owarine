<AppLink href="/proof">Proof</AppLink> lists settled Windows. Open a row to see that Window's **proof page**: the opening and closing boundary values, each oracle party's quote at the close, the median the resolver took, and the outcome or the void reason. The resolver settles from these recorded quotes, not from the latest display price.

## The resolution timeline

Each proof page walks through the Window's life in order: opened, opening print recorded, closing quotes posted by each oracle, resolved or voided. Beside it, the trust boundary says who could have done what: the oracles post prices, the resolver decides, and the venue alone cannot resolve.

## Check the evidence

Each oracle quote carries the hash of the raw exchange response it was read from, and that response is archived byte for byte. Anyone can hash the archived payload, compare it with the quote, and read the candle's close from it. An absent archived payload should be treated as unavailable evidence even if the quote itself is on the ledger.
