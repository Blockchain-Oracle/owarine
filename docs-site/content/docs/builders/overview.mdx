This documentation site lives in the Owarine application repository at `docs-site/`. The app is a prediction market on Canton Network: the rules are Daml packages in `daml/` (five released as R1, and governance on LocalNet), the venue's actors are in `services/ops/`, and the web and phone apps read and write through `packages/markets` and `packages/ledger`.

Use [Local setup](/builders/local-setup) for the actual commands, [Source map](/builders/source-map) to locate each system, [The Daml packages](/architecture/programs) for the contracts, and [Price sources](/architecture/price-sources) for the oracle path. A local sandbox run and a DevNet run are different kinds of evidence: `.github/verification/capabilities.json` preserves each capability's recorded state and evidence. Historical evidence uses immutable Git references; `.github/verification/acceptance.md` includes the dated DevNet first-call and Canton Coin records. `live` means recorded DevNet execution, not current service availability.
