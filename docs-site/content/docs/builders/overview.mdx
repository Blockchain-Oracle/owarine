This documentation site lives in the Agari application repository at `docs-site/`. The app is a prediction market on Canton Network: the rules are four Daml packages in `daml/`, the venue's actors are in `services/ops/`, and the web and phone apps read and write through `packages/markets` and `packages/ledger`.

Use [Local setup](/builders/local-setup) for the actual commands, [Source map](/builders/source-map) to locate each system, [The Daml packages](/architecture/programs) for the contracts, and [Price sources](/architecture/price-sources) for the oracle path. A local sandbox run and a DevNet run are different kinds of evidence: `docs/plan/capabilities.json` marks each capability `local` or `live`, and every `local` entry names its evidence note in `docs/evidence/`. Today nothing is `live`.
