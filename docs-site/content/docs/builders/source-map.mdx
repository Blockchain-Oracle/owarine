title: "Source map and evidence"
description: "Where each documented behavior lives in the Agari checkout, and what evidence backs it."
---

The docs live in the same repository at `docs-site/`, and the paths below are relative to its root.

| Behavior | Source owner | Evidence boundary |
| --- | --- | --- |
| Contracts: Series, Window terms, prints, quotes, legs, cash, resolution | `daml/abu-pm-main/daml/PM/` | The `daml/pm-tests` scripts (money conservation, privacy, races, resolution) |
| Ledger client and Daml bindings | `packages/ledger/src/`, `packages/daml-clients/` (generated) | Unit tests and a sandbox integration test |
| Seats: lease, cookie, funding, drain | `web/src/lib/seat-lease.server.ts`, `web/src/app/api/seat/`, `packages/markets/src/server/`, `services/ops/src/actors/seat-funding/` | Seat routes tested end to end on a local sandbox |
| Venue actors: roller, pricer, issuer, sweeper, netting, settler | `services/ops/src/actors/venue/` and the actor folders beside it | Local drive reports in `docs/evidence/` |
| Oracle feeders and resolver | `services/ops/src/actors/price-relay/oracle-feeder.ts`, `services/ops/src/actors/resolver/` | Archived raw payloads and their hashes; per-Window evidence in `docs/evidence/` |
| Projector and reads | `services/ops/src/actors/projector/`, `packages/db/src/`, `web/src/app/api/index/` | A rebuild replays the ledger into a second database and must match the live one |
| Proof pages | `web/src/features/proof/`, `web/src/app/proof/` | Each print and resolution rendered from ledger data and its archive |
| Registry, baskets and integer index | `packages/core/src/market/baskets.ts` | Frozen member bases and arithmetic; basket lanes are **planned** on Canton |
| Closed-market board and session lines | `web/src/features/markets/word-board/`, `packages/core/src/market/horizons.ts`, `packages/core/src/copy/session-words.ts` | Behavior depends on the hour; read the live board |
| Desk rules and record | `packages/core/src/desk/`, `packages/markets/src/desk/`, `services/ops/src/actors/desk-runner/` | Paper practice only; the Canton live leg is **planned** |

The acceptance ledger, `docs/evidence/acceptance.md`, records each gate and whether it ran on a local sandbox or a shared test network. The other products (Range, Boost, Parlay, Earn, strategies, games) keep their screens in the matching `web/src/features/` folders while their Daml contracts are **planned**.
