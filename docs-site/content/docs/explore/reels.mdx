---
title: "Reels and takes"
description: "Read public seat-signed takes and understand what the backed badge proves."
---

Open <AppLink href="/reels">Reels</AppLink> under **More → Learn**. The feed mixes live Windows with public takes and, when available, your desk's decision.

A **take** names a Window and side, with an optional short explanation. Posting signs a message with your seat's key. The server verifies it before saving the take. It is not a Canton trade and spends no test credits.

A **backed** badge requires a call on that Window that its owner chose to publish. The server checks the public record; a client cannot assert the badge, and an unpublished position is not exposed to earn one. The badge proves that link, not that the call will win.

Ticker chips open the relevant ticker hub. Read the author, Window and age before opening a ticket; a take itself accepts no quote for you.

Takes need the social store. If the composer says **Takes aren't connected yet**, the feed can still show Windows, but no post was saved. A visible draft or signature alone is not a posted take.
