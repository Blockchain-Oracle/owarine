---
title: "Ask Sensei for a read"
description: "Ask about the current ticker and review a suggested card yourself."
---

Open **More → More ways to trade → Sensei**. The dock uses the ticker, session and available position context to answer questions. It can hand a trade card to the ticket; it does not place that trade for you.

1. Open a ticker or position and then Sensei.
2. Ask a question about the available context.
3. Read the response and any limits it names.
4. If you open a trade card, review the current Window, amount and quote yourself before confirming.

Sensei has a brake against investment advice and promised outcomes. Its response is not a price oracle or settlement evidence. Only the Window's signed prints decide its result.

A model provider and server credential must be configured. The dock can render while the model is unavailable; read its actual reply or failure state, and the Sensei model check on [Status](/help/status). A displayed dock alone does not establish a successful model response.
