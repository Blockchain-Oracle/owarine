A Window settles from its opening and closing **boundary prints**. The web app never picks a winner from a latest-price tile: the resolver party resolves the Window on the ledger, from the oracle parties' signed quotes, under the price policy the Window opened with.

<Architecture name="prints" />

| Step | What happens |
| --- | --- |
| Oracle quotes | Three oracle parties each read the Window's named source themselves and post a `PriceQuote` per boundary. |
| Evidence | The raw response is archived byte for byte and its sha-256 is on the quote, so the price can be re-derived. |
| Quorum | At least 2 of the 3 oracles need a valid quote inside the boundary's admission window. Fewer, and it voids. |
| Agreement | A spread over 1% of the quotes' median voids the Window instead of paying anyone. |
| Once | A Window resolves or voids exactly once. A void returns every stake plus its fee. |
| Tie | A close equal to the open pays Up. |

## The named sources

Each Series' policy text names its source, and every receipt and proof page repeats it.

| Lane | Source | State on the local sandbox |
| --- | --- | --- |
| BTC, ETH | Coinbase, Kraken and Bitstamp 1-minute candle closes | Resolved from 1-minute to 1-hour Windows; 4-hour and 1-day Windows listed. |
| TSLA, NVDA, AAPL, MSFT, META, AMZN, GOOGL | RedStone, admitted up to 15 minutes after the boundary | Resolved in session, with the Alpaca calendar keys set. |
| QQQ, VOO | Alpaca (last IEX trade) in the 5 minutes before the boundary | Resolved in session. |
| TSLAx, NVDAx, SPYx, QQQx | Jupiter Price v3 (median of three samples in the last 40 s) | Resolved; Switchboard Surge is down upstream. |
| Eight pre-IPO names, five baskets | PreStocks catalogue; a basket is an index in points from one read of every member | Resolved hourly; paused while PreStocks rate-limits the host. |
| Events | A committee of the three oracle parties, quorum 2 | Resolved YES, and voided on a split. |

Policy versions are append-only on the Series, and a Window keeps the version it opened under: QQQ and VOO moved to Alpaca, and the xStocks to Jupiter Price v3, as new versions. Pyth is not used, because there is no entitled key.

A lane's [halt](/trading/halts-and-voids) is judged on the source in this table and on no other: RedStone package age for the seven stocks, the last IEX trade for QQQ and VOO, the issuer's flag and Jupiter Price v3 read failures for the xStocks, the PreStocks read for the pre-IPO names and baskets. The halt watcher takes each lane's source from the same table the venue registers its Series from, so the two cannot disagree, and it makes no Pyth request while no lane settles on Pyth.

These are feeders the venue runs itself: three independent exchanges for crypto, one named source attested three times for the rest. Neither is an independent oracle network, and the pages say so.
