Pre-IPO and basket Windows use **attested reads**. Owarine's oracle parties read the named provider and sign `PriceQuote` contracts on Canton. The provider does not sign a Canton contract itself.

## PreStocks

The PreStocks catalogue supplies token prices and mark prices. The code registers eight names: OpenAI, Anthropic, SpaceX, Neuralink, Anduril, Kalshi, Polymarket and Figure AI.

| Use | What the source does |
| --- | --- |
| Pre-IPO Window | Each oracle reads the named token price near the boundary and posts its quote with the source payload hash. |
| Basket Window | Computes an equal-weight index in points from frozen member base prices. A valid read of every member is required. |
| Price page | Shows the token price and mark, where available. This display does not settle a Window. |
| Desk | Supplies price reads for the runner; a funded mandate also uses oracle marks for its ledger checks. |

The feeder's PreStocks read window is **T + 10 to T + 45 seconds**. The Window's terms determine admission and resolution deadlines. Ops backs off on provider rate limits and respects `Retry-After` when available. A provider problem can pause quoting or prevent required prints.

Local-sandbox pre-IPO and basket resolution evidence exists. It does not establish current provider access or hosted acceptance of every lane. Check <AppLink href="/status">Status</AppLink> and each Window's frozen source policy.

## Pyth entitlement

The Pyth adapters can fetch price or valuation-index data and attest it through the same Canton `PriceQuote` path. Valuation indices need an **entitled provider key**. The entitlement actor probes that access; the roller uses the result when deciding whether to list a valuation lane.

A company valuation index and a token price are different measurements. The presence of an index adapter does not make it the settlement source for a token Window. QQQ and VOO have an Alpaca last-IEX-trade path; read the actual Series policy for the source a Window uses.

This review did not inspect server credentials or establish current Pyth entitlement. A source adapter in the repository is not evidence that a provider is connected.
