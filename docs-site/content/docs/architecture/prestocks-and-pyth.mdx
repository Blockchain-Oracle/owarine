On Canton, every Window settles from prints signed by the venue's **oracle parties** ([Price sources](/architecture/price-sources)). Today those parties post crypto prices from three exchanges. **PreStocks** and **Pyth** prices are **planned** to arrive the same way: the oracle feeders fetch them off the ledger and post them as signed quotes, with the original source named on every receipt. None of the lanes on this page settles on Canton yet. Dates are UTC.

## PreStocks (planned)

[PreStocks](https://prestocks.com) publishes tokenized pre-IPO stocks and a public catalogue, [`prestocks.com/api/prestocks`](https://prestocks.com/api/prestocks), with each name's token price and the SPV's mark price. The catalogue is unsigned, so a PreStocks print on Canton would be the venue's oracle parties attesting what they read from PreStocks — an honest, re-derivable read of PreStocks data, not an independent oracle.

The eight names are OpenAI, Anthropic, SpaceX, Neuralink, Anduril, Kalshi, Polymarket and Figure AI. PreStocks states that its tokens are not affiliated with, endorsed by or issued by the companies they reference, and are not available in the U.S.

| Where | What PreStocks would supply |
| --- | --- |
| The OpenAI 24/7 lane | A one-hour Up/Down Window on the OpenAI token price, every hour of every day. |
| Five baskets | Equal-weight indices in points (base 1,000 at frozen base prices) over PreStocks names, each computed from one catalogue read of every member; a partial read produces no print. See [Baskets](/trading/baskets). |
| The desk's premium ceiling | A desk never buys a name more than its owner's ceiling above the PreStocks mark. See [How the desk decides](/architecture/desk). |
| Pre-IPO pages | Each name's page shows the token price, the PreStocks mark and the premium or discount between them. These read the catalogue today and settle nothing. |

**Cover what you hold** needs to read a holder's tokens. A seat holds no outside tokens, so cover shows its "no holdings" state until Canton Coin and CIP-56 token holdings are wired (planned).

## Pyth (planned)

Pyth publishes equity prices (for example [TSLA/USD](https://app.pyth.com/explore/Equity.US.TSLA%2FUSD), [QQQ/USD](https://app.pyth.com/explore/Equity.US.QQQ%2FUSD), [VOO/USD](https://app.pyth.com/explore/Equity.US.VOO%2FUSD)) and pre-IPO valuation indices for [OpenAI](https://app.pyth.com/explore/Equity.Index.OPENAI%2FUSD) and [Anthropic](https://app.pyth.com/explore/Equity.Index.ANTHROPIC%2FUSD). There is no Pyth contract on Canton, and none is needed for an attested print: the plan is for the oracle feeders to fetch the Pyth update for the exact boundary second, archive it byte for byte, and post it through the same quorum as every other print.

The same rules would apply as for crypto: a missing print or a disagreement past the Series' limit voids the Window instead of paying anyone, and a Window keeps the price policy it opened under.

The valuation indices need an entitlement the venue's current key does not have. While the key is refused, no valuation Window is listed, and the index rows are left off the pages rather than shown dead. The index measures company valuation while a token Window settles on the token price, so Agari never uses one as a cross-check for the other.
